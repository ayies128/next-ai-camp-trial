# 補助説明プロンプト（AI 用）

## 使う場面

**教材の正本は `knowledge/lessons/session-00`〜`session-03` です。**

このプロンプトは、教材を読み進める中で「別の例えがほしい」「この1か所だけ、もっと小さく分けてほしい」と感じたときの補助です。AI に新しい教材・別のカリキュラム・完成した答えを作らせるためには使いません。

## プロンプト

```text
Session {番号} の教材を進めていて、「{引っかかっている用語・操作}」がまだ腹落ちしていない。

教材の内容を変えずに、この1つだけ補助して。
- まず英語としての意味と、なぜその名前かを説明して
- 例え話は1つだけにして、最後は正式な意味に戻して
- 説明の直後に、30秒〜2分で結果を確かめられる「みてみて」か「やってみて」を1つ出して
- 私が反応するまで次の概念へ進まないで
- 詰まったら、完成した答えではなく次の1手だけヒントを出して
```

## 補足

- 例: `git add` の後に何が変わるのか、`origin` と `upstream` の違い、`cd` がどこへ移動するのか
- 「教材を最初から作って」は、この体験版の学び方では使いません。固定教材を少しずつ自分で確かめることが目的です
- Claude Code と Codex のどちらでも使えます
