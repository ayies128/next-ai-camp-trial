# 閉本再現と理解チェックのプロンプト（AI 用）

## 使う場面

閉本再現と理解チェックは、AI がセッション終了前に自分から行う必須の手順です。AI が飛ばしそうなときだけ、下の文を送ってください。

## プロンプト

```text
Session {番号} の閉本再現と理解チェックをしたい。

最初に、教材と今日のメモ・コマンド履歴を閉じるよう伝えて。
そのあと、今日の課題を少しだけ変えた仕様または質問を1つだけ出して。

- 私が見ないで説明・操作し終えるまで、答えや完成したコマンド列を先に見せないで
- 詰まったら、答えではなく「次の1手」だけヒントを出して
- 終わったら、なぜその操作をしたかを私の言葉で説明させて
- Session 00 は口頭での再現、Session 01〜03 は操作を含む再現にして

閉本再現のあと、理解チェックを1問ずつ出して。
- 簡単な用語の意味は選択肢を付けず、記述式で聞いて
- 選択式にするのは、実行結果・間違い探し・使い分け・エラー原因・操作順の問題だけ
- 選択肢は、初心者が実際に迷いそうなものにして。「すべて正しい」「どれも違う」は使わないで
- 答えた後に短い解説を付け、怪しかったところを最後にまとめて
```

## 大事なこと

「動いた」だけでは完了ではありません。見ないでできて、理由を説明できることが合格ラインです。詰まった場所は失敗ではなく、次回に復習する場所が分かった成果です。
