# 進行を再開するためのプロンプト（AI 用）

## 使う場面

通常は不要です。AI は `AGENTS.md` のルールに従って、学習者が「始めます」「続きから」と言った時点で次の Session を判断して進行します。

新しい会話を始めたときなど、AI が前回からの続きとして動かなかった場合だけ、下の文を送ってください。

## プロンプト

```text
このリポジトリの AGENTS.md を読んで、体験版の進行役になって。

最初に knowledge/profile.md と knowledge/sessions/ の最新記録を読んで、
Session 00〜03 のうち、私が次に進むべき固定の Session を判断して。
初回なら Session 00 から始めて。

私にテーマや読む文書を選ばせず、対応する knowledge/lessons/ の教材を
正確なパスで指定して、1概念1アクションで進めて。
用語は英語の意味から説明し、最後は閉本再現・理解チェック・学習記録と
カルテの更新までリードして。

教材そのものを新規生成したり、Session 00〜03 の範囲外へ進めたりはしないで。
この段階では npm、Next.js、.tsx を使わないで。
```

## 補足

- Claude Code と Codex のどちらでも使えます
- 返答の最初に「前回は〜、今日は〜」と短く状況を説明してくれれば、正しく記録を読めています
- 初回は、AI が Session 00 の中で `knowledge/profile.example.md` を基にカルテを作ります
