# 学習記録とカルテを更新するプロンプト（AI 用）

## 使う場面

記録とカルテの更新は、AI がセッション終了前に自分から行う必須の手順です。学習者から頼む必要はありません。

AI が記録を書かずに終えようとしたときだけ、下の文を送ってください。

## プロンプト

```text
今日の Session {番号} の学習記録と学習者カルテを更新して。

1. knowledge/sessions/YYYY-MM-DD-session-XX-テーマ.md に学習記録を保存して。
   次の見出しを必ず全部入れて:
   - 今日のテーマ
   - やったこと
   - 学んだこと
   - ⚠️ 詰まったところ
   - 💪 スムーズだったところ
   - 📕 閉本再現の結果
   - 理解できていないこと
   - 理解度チェック結果
   - 次やること

   「詰まったところ」は具体的に書いて。
   例: 「git add の後に何が変わるかが結び付かず、表示を見比べるヒントが必要だった」。

2. knowledge/profile.md を更新して。無い場合は knowledge/profile.example.md を基に作って。
   次の観点を、既存の内容を消さずに更新して:
   - 得意そうなこと
   - つまずきやすいパターン
   - 効いた教え方 / 効かなかった教え方
   - ペース
   - 次回の指導方針

カルテは私自身も読むもの。否定的な書き方はせず、
「できていない」ではなく「もう一度触れると定着しそう」と書いて。
書き終えたら、保存したファイルと次回最初にすることを短く報告して。
```

## 補足

- AI は次回の開始時、カルテと最新の学習記録を読んでから進行します
- 記録は「何をしたか」の一覧ではなく、次回どこから助ければよいかを残すための申し送りです
- Claude Code と Codex のどちらでも使えます
