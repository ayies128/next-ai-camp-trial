# 用語辞典 — 英語の意味から覚える

> プログラミングの用語の多くは、普通の英単語です。`add` は「追加する」、`push` は「押し出す」。意味と役割をつなげると、暗記する量が減ります。
>
> 分からない言葉に出会ったら、このページへ戻るか、AI に「英語の意味から教えて」と聞いてください。

## この辞典の見方

| 項目 | 意味 |
| --- | --- |
| **英語の意味** | IT と関係ない、普通の英語としての意味 |
| **この教材での意味** | 今回何を指しているか |
| **初登場** | 最初に使う Session |

## 学び方とプロジェクト

### Session（セッション）

- **英語の意味**: 会合、ひと区切りの時間
- **この教材での意味**: 1 回分の学習単位。
- **初登場**: Session 00

### Phase（フェーズ）

- **英語の意味**: 段階、局面。
- **この教材での意味**: 予習から記録まで、毎回の学習を進める順番の区切り。
- **初登場**: Session 00

### Project（プロジェクト）

- **英語の意味**: 計画、企画。
- **この教材での意味**: 目的を持って進める仕事や学習のまとまり。この教材リポジトリ全体も 1 つのプロジェクト。
- **初登場**: Session 00

### Lesson（レッスン）

- **英語の意味**: 授業、学び。
- **この教材での意味**: Session の中で読む学びの内容。`knowledge/lessons/` に置かれている。
- **初登場**: Session 00

### Repository / repo（リポジトリ / リポ）

- **英語の意味**: repository = 保管庫。repo はその略。
- **この教材での意味**: ファイルと、その変更履歴をまとめて置く場所。
- **初登場**: Session 00

### Fork（フォーク）

- **英語の意味**: 食器のフォーク、道の枝分かれ。
- **この教材での意味**: 他の人のリポジトリを、自分の GitHub アカウントの下にコピーすること。
- **初登場**: Session 00

### Clone（クローン）

- **英語の意味**: 複製、同じものを作ること。
- **この教材での意味**: GitHub 上のリポジトリを、履歴ごと PC に取り込むこと。
- **初登場**: Session 00

### Prompt（プロンプト）

- **英語の意味**: 行動を促すもの、きっかけ。
- **この教材での意味**: AI に送る指示や質問の文章。
- **初登場**: Session 00

### AI（エーアイ）

- **英語の意味**: Artificial Intelligence。artificial = 人工の、intelligence = 知能。
- **この教材での意味**: 質問に答えたり、ファイルを読んだりする学習パートナー。答えを代筆させるのではなく、ヒント・説明・確認役として使う。
- **初登場**: Session 00

### Profile（プロフィール）

- **英語の意味**: 人物紹介、横顔。
- **この教材での意味**: 目標やつまずき方を残す、自分用の学習カルテ。
- **初登場**: Session 00

## ファイルとターミナル

### File（ファイル）

- **英語の意味**: 書類、記録。
- **この教材での意味**: 文章、画像、プログラムなどを、名前を付けて保存するデータの 1 単位。
- **初登場**: Session 01

### Folder / directory（フォルダ / ディレクトリ）

- **英語の意味**: folder = 書類ばさみ、directory = 案内表・名簿。
- **この教材での意味**: ファイルを整理して入れる場所。同じものを、画面ではフォルダ、ターミナルではディレクトリと呼ぶことがある。
- **初登場**: Session 01

### Path（パス）

- **英語の意味**: 道、経路。
- **この教材での意味**: ファイルやフォルダがどこにあるかを示す住所。
- **初登場**: Session 01

### Extension（拡張子）

- **英語の意味**: 拡張、付け足すこと。
- **この教材での意味**: `.md` や `.txt` のような、ファイル名の最後に付く種類の名札。
- **初登場**: Session 01

### Relative path / absolute path（相対パス / 絶対パス）

- **英語の意味**: relative = 比べて決まる、absolute = それ自体で決まる、path = 道・経路。
- **この教材での意味**: 相対パスは今いる場所から書く住所、絶対パスは PC の最初から書く住所。体験版では相対パスを使う。
- **初登場**: Session 01

### Terminal（ターミナル）

- **英語の意味**: 端末、終着駅。
- **この教材での意味**: 文字で PC に命令を出す画面。
- **初登場**: Session 01

### Command（コマンド）

- **英語の意味**: 命令。
- **この教材での意味**: ターミナルに打ち込む、PC への 1 つの指示。
- **初登場**: Session 01

### `pwd`

- **英語の意味**: Print Working Directory。print = 表示する、working = 作業中の、directory = フォルダ。
- **この教材での意味**: 今いるフォルダを表示するコマンド。
- **初登場**: Session 01

### `ls`

- **英語の意味**: list（一覧にする）の略。
- **この教材での意味**: 今いるフォルダの中身を一覧するコマンド。
- **初登場**: Session 01

### `cd`

- **英語の意味**: Change Directory。change = 変える、directory = フォルダ。
- **この教材での意味**: 今いるフォルダを別のフォルダへ移すコマンド。
- **初登場**: Session 01

### `mkdir`

- **英語の意味**: make directory。make = 作る、directory = フォルダ。
- **この教材での意味**: 新しいフォルダを作るコマンド。
- **初登場**: Session 01

## Git

### Git（ギット）

- **英語の意味**: 道具の固有名詞。特定の英語の略ではない。
- **この教材での意味**: ファイルの変更履歴を記録し、以前の状態を確認できる道具。
- **初登場**: Session 02

### Version（バージョン）

- **英語の意味**: 版、改訂版。
- **この教材での意味**: ある時点で確定したファイルの状態。
- **初登場**: Session 02

### `git status`

- **英語の意味**: status = 状態。
- **この教材での意味**: 変更があるか、次の記録に選ばれているかを確認するコマンド。
- **初登場**: Session 02

### `git add`

- **英語の意味**: add = 追加する。
- **この教材での意味**: 次の記録に入れたい変更を選ぶコマンド。
- **初登場**: Session 02

### Stage（ステージ）

- **英語の意味**: 舞台、準備段階。
- **この教材での意味**: `git add` した変更を、commit 前に置いておく準備場所。
- **初登場**: Session 02

### `git commit`

- **英語の意味**: commit = 確定する、約束する。
- **この教材での意味**: 選んだ変更を、メッセージ付きの履歴として確定するコマンド。
- **初登場**: Session 02

### `git log`

- **英語の意味**: log = 記録、日誌。
- **この教材での意味**: 確定済みの履歴を一覧するコマンド。
- **初登場**: Session 02

### `git diff`

- **英語の意味**: difference（違い）の略。
- **この教材での意味**: 変更前と変更後の差を表示するコマンド。
- **初登場**: Session 02

### `-m` / `--staged`

- **英語の意味**: message = 伝える文章、staged = stage（準備場所）に入った状態。
- **この教材での意味**: `-m` は commit の理由を書く指定。`--staged` は `git add` 後の、次に記録する予定の変更だけを `git diff` で見る指定。
- **初登場**: Session 02

## GitHub と共同作業

### GitHub（ギットハブ）

- **英語の意味**: Git + hub。hub = 人や物が集まる拠点。
- **この教材での意味**: Git のリポジトリをネット上に置き、見たり共有したりするサービス。
- **初登場**: Session 03

### Remote（リモート）

- **英語の意味**: 遠くの、離れた。
- **この教材での意味**: PC の外、ネット上にあるリポジトリの通信相手。
- **初登場**: Session 03

### Origin（オリジン）

- **英語の意味**: 起点、出どころ。
- **この教材での意味**: クローンした先に Git が付ける定番の名前。この教材では自分のフォークを指す。
- **初登場**: Session 03

### Upstream（アップストリーム）

- **英語の意味**: 川の上流。
- **この教材での意味**: フォーク元の教材本体を指す定番の名前。教材の更新が流れてくる大元。
- **初登場**: Session 03

### Push（プッシュ）

- **英語の意味**: 押す、押し出す。
- **この教材での意味**: PC で作った commit を GitHub へ送ること。
- **初登場**: Session 03

### Pull（プル）

- **英語の意味**: 引く、引き寄せる。
- **この教材での意味**: GitHub にある commit を PC へ取り込むこと。
- **初登場**: Session 03

### Branch（ブランチ）

- **英語の意味**: 木の枝。
- **この教材での意味**: `main` を直接変えずに、別の流れで変更を試すための作業場所。
- **初登場**: Session 03

### Main（メイン）

- **英語の意味**: 主要な、中心の。
- **この教材での意味**: リポジトリの基本となる中心のブランチ。
- **初登場**: Session 03

### Pull request / PR（プルリクエスト / ピーアール）

- **英語の意味**: pull = 取り込む、request = お願い。
- **この教材での意味**: ブランチの変更を main に取り込んでほしいと提案し、内容を確認する GitHub の仕組み。
- **初登場**: Session 03

### Merge（マージ）

- **英語の意味**: 合流する、1 つに合わせる。
- **この教材での意味**: ブランチの変更を main に取り込むこと。
- **初登場**: Session 03

### `git switch`

- **英語の意味**: switch = 切り替える。
- **この教材での意味**: 作業するブランチを切り替えるコマンド。`-c` を付けると create（作る）の指定になり、新しいブランチを作って切り替える。
- **初登場**: Session 03

### Review（レビュー）

- **英語の意味**: re = もう一度、view = 見る。見直すこと。
- **この教材での意味**: PR に入る変更と合流先を、マージ前に確認すること。
- **初登場**: Session 03
