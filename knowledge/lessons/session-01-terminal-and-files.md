## 🗣 今日の新出用語

| 用語 | 英語の意味 | 一言でいうと |
| --- | --- | --- |
| file（ファイル） | 書類・記録 | PC に保存するデータの 1 単位 |
| folder / directory（フォルダ / ディレクトリ） | 書類ばさみ / 案内表 | ファイルをまとめる入れ物 |
| path（パス） | 道・経路 | ファイルやフォルダの住所 |
| extension（拡張子） | 拡張・付け足すこと | ファイルの種類を示す名札 |
| relative / absolute（相対 / 絶対） | 比べて決まる / それ自体で決まる | 今いる場所から書く住所 / 最初から書く住所 |
| terminal（ターミナル） | 端末・終着駅 | 文字で PC を操作する窓口 |
| command（コマンド） | 命令 | ターミナルに打つ指示 |
| `pwd` | Print Working Directory | 今いる場所を表示する |
| `ls` | list | 今いる場所の一覧を出す |
| `cd` | Change Directory | 別のフォルダへ移動する |
| `mkdir` | make directory | 新しいフォルダを作る |

→ 詳しくは [用語辞典](../glossary.md) を見てください。

## 📖 理論パート — 読みながら小さく確かめる

### 1. PC の中身はファイルとフォルダで整理されている

**file（ファイル）= 英語で「書類・記録」**です。メモ、写真、プログラムの材料はすべてファイルとして保存されます。**folder（フォルダ）= 書類ばさみ**は、それらをまとめる入れ物です。ターミナルでは同じものを **directory（ディレクトリ）= 案内表** と呼ぶことがあります。

ファイル名の最後の `.md` や `.txt` は拡張子です。これは「このファイルはどんな種類か」を示す名札です。

> 👀 **みてみて**: VS Code 左側のファイル一覧で、`README.md`、`AGENTS.md`、`practice/` を探してください。文章、ルール、練習場と役割は違っても、どれもファイルまたはフォルダです。

### 2. パスは目的地までの住所

**path（パス）= 英語で「道・経路」**です。PC の中の目的地までの道筋を、文字で書いた住所だと思ってください。

今いる場所からの道を **relative（リラティブ）= 相対的な**パス、PC のいちばん上から書く住所を **absolute（アブソリュート）= 絶対的な**パスといいます。今日は相対パスだけで十分です。たとえば `practice/session-01-terminal` は、「いま開いている教材フォルダから、practice を通って session-01-terminal へ」という道順です。

> 👀 **みてみて**: 左のファイル一覧で `practice` → `session-01-terminal` と順に開いてください。フォルダを開くたびに、目的地までの道が 1 つずつ増える感覚をつかみます。

### 3. ターミナルは文字で命令を出す窓口

**terminal（ターミナル）= 英語で「端末」**です。文字を打って PC に命令を出す画面です。そこで打つ命令を **command（コマンド）= 命令** と呼びます。

VS Code では、上のメニューから「ターミナル」→「新しいターミナル」で開けます。画面下に文字を打てる場所が現れたら準備完了です。

> ✋ **やってみて**: VS Code でターミナルを開き、次を打って Enter を押してください。

```bash
pwd
```

`pwd` は **Print Working Directory** の略です。print = 表示する、working = 作業中の、directory = フォルダ。つまり「作業中のフォルダを表示して」です。表示の最後が `next-ai-camp-trial` なら、教材の入口にいます。

### 4. 4 つのコマンドで「見る・移動する・作る」ができる

まず `ls`。**list = 一覧にする**の略で、「ここには何がある？」を見る命令です。

```bash
ls
```

次に `cd`。**Change Directory = フォルダを変える**の略です。

```bash
cd practice/session-01-terminal
```

1 つ上へ戻る `cd ..` の `..` は「親フォルダ」を表します。フォルダを作る `mkdir` は **make directory = フォルダを作る**の略です。

> ✋ **やってみて**: 下の 4 行を、1 行ずつ打ってください。途中で表示されるものを見てから次へ進みます。

```bash
ls
cd practice/session-01-terminal
pwd
mkdir my-terminal-space
```

最後の行で「すでにあります」と出た場合は、`my-terminal-space-2` のように別の名前にしてください。作ったフォルダは、この後の自分用の練習場です。

## 🎨 演習課題（20 分）

### 課題 1: ターミナル宝探し

`practice/session-01-terminal/` には `treasure.txt` が隠れています。マウスでファイルを開かず、ターミナルだけで探してください。

使ってよいのはこの 3 つです。

```bash
ls
cd フォルダ名
cd ..
```

迷子になったら、現在地を調べます。

```bash
pwd
```

始める場所に戻るには、教材のいちばん上のフォルダから次を打ちます。

```bash
cd practice/session-01-terminal
```

`ls` の一覧に `treasure.txt` が表示された時点で成功です。宝探し中に中身を開く必要はありません。終わった後に読みたければ、VS Code のファイル一覧から開いてください。答えの道順を AI に最初から聞かないこと。どうしても止まったら「今いる場所から、次に確認するコマンドを 1 つだけ教えて」と聞きます。

### 課題 2: 自分の場所へ往復する

さっき作った `my-terminal-space`（または自分で付けた名前）へ移動し、入口へ戻ります。

1. `pwd` で今いる場所を確認する
2. `cd` で自分のフォルダへ入る
3. `pwd` でもう一度確認する
4. `cd ..` で 1 つ上へ戻る
5. `ls` で、自分のフォルダ名が見えることを確かめる

> 💡 フォルダの中身を暗記する必要はありません。「迷ったら `pwd`、選択肢を見るなら `ls`」を体に覚えさせる課題です。

## 🆘 つまずき FAQ

### Q: `cd practice/session-01-terminal` で「見つからない」と出る

A: まず `pwd` を打って、表示の最後が `next-ai-camp-trial` か確認してください。違う場所なら、VS Code で教材フォルダを開き直して新しいターミナルを開くのが安全です。

### Q: `mkdir` が「すでにあります」と言う

A: 前に同じ名前で作れています。`ls` で確認し、そのフォルダを使うか、末尾に `-2` をつけた別名を使ってください。

### Q: 画面が英語で怖い

A: エラーの全文を AI に貼り、「この英語を日本語にして。今は何を確認すればよいか 1 つだけ教えて」と頼んでください。
