# 📝 学習記録 — 考えた跡を残す場所

このフォルダには、各 Session の学習記録が入ります。
**AI がセッションの終わりに自動で作成・更新します。** あなたがファイル名を考えたり、毎回保存を頼んだりする必要はありません。

記録に残すのは「やったこと」だけではありません。

- 自分でどう考えたか
- どこでつまずき、どう抜けたか
- 教材を閉じて再現できたか
- 次にもう一度触れたいこと

間違いや詰まりも大切な学習の記録です。空欄にせず、AI と一緒に残します。

---

## ファイル名

```text
YYYY-MM-DD-session-XX-テーマ.md
```

例:

```text
2026-08-18-session-01-terminal-and-files.md
```

このフォルダ内の個人の学習記録は Git に保存されません。安心して、自分の言葉や困ったことを書けます。

---

## 記録の形

AI は各回、だいたい次の内容を残します。

```markdown
# Session XX: テーマ

📅 日付:
🎯 今日のゴール:

## 自分で考えたこと

## 今日できたこと

## つまずいたところと、抜けた方法

## 閉本再現の結果

## 自分の言葉で説明すると

## 次にやること
```

後から「続きから始めよう」と AI に送ると、AI はこの記録と `knowledge/profile.md` を読んで、前回の続きから案内します。
