========================================
  ターミナル宝探し へようこそ！
========================================

このフォルダのどこかに treasure.txt（宝物）が隠されています。
マウスは使わず、ターミナルのコマンドだけで探し出してください。

使うのはこの 3 つだけ:

  ls        いまいる場所を一覧する（list = 一覧にする）
  cd 名前   そのフォルダに入る（change directory = 場所を変える）
  cd ..     1 つ上のフォルダに戻る（.. = 1 つ上）

迷子になったら:

  pwd       いま自分がどこにいるか表示する
            （print working directory）

それでは、ls から始めてください。よい冒険を！

（フォルダ名の意味: forest = 森 / castle = 城 / cave = 洞窟 /
  tower = 塔 / basement = 地下室 / secret = 秘密）
