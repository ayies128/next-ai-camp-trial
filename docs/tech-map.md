# Web エンジニアリングの技術地図 — 体験版の現在地

> Web アプリは、バラバラの技術を寄せ集めたものではありません。画面を作る技術、データを扱う技術、世界に届ける技術がつながっています。
> このページはその全体地図です。各 Session の「🗺 いまここ」から、いつでも戻れます。

---

## Web サービスは3つの技術層と、共通の道具でできている

```text
あなた（使う人）
  ↓
① フロントエンド  … 画面・見た目・操作を作る
  ↓
② バックエンド    … データを保存し、処理する

③ インフラ        … ①と②を動かし、インターネットへ届ける土台

⓪ 共通の道具      … どの層でも使う、ターミナル / Git / GitHub / AI との協働
```

| 区分 | 英語の意味 | 何をする場所？ | 例 |
|---|---|---|---|
| **① フロントエンド** | front end = 前側 | 利用者が見る画面を作る | HTML / CSS / JavaScript / React |
| **② バックエンド** | back end = 後ろ側 | データを保存し、処理する | データベース / API / 認証 |
| **③ インフラ** | infrastructure = 基盤・土台 | アプリを動かし、公開する | サーバー / ドメイン / Vercel |
| **⓪ 共通の道具** | — | すべての層で使う操縦席 | ターミナル / Git / GitHub / AI |

> **フルスタック**（full = 全部の、stack = 積み重ね）は、①〜③のすべてに触れられることです。本編はこの地図を小さく1周します。

## 体験版の現在地

体験版は、いきなり画面づくりに入らず、全レイヤーで使う **⓪ 共通の道具** を先に扱います。

| Session | テーマ | 地図上の位置 | この回で整えること |
|---|---|---|---|
| 0 | プロジェクトの歩き方 | ⓪ 共通の道具 | AI と一緒に学ぶ進め方 |
| 1 | ターミナルとファイルの世界 | ⓪ 共通の道具 | パソコンを操作するための操縦席 |
| 2 | Git ってなに？ | ⓪ 共通の道具 | 変更を安全に記録するセーブポイント |
| 3 | GitHub を使ってみよう | ⓪ 共通の道具 | 記録をオンラインで共有する置き場 |

> ブラウザで触れる60秒プレビューは、あとで学ぶ **① フロントエンド** の完成見本です。体験版の必修課題ではありません。
