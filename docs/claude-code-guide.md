# Claude Code を選んだ人向けガイド

> この体験版は **Claude Code と Codex のどちらでも進められます。**
> ここは Claude Code を選んだ人だけが読む補助ガイドです。Codex を選んだ人は [セットアップガイド](./setup.md) の案内どおり、Codex のパネルから始めてください。

---

## Claude Code は何をする相手？

Claude Code は、プロジェクト内のファイルを読んだり、説明したり、必要なら編集やコマンドの実行を手伝ったりできる AI です。

この教材では、最初から「コードを書いてくれる人」にするのではなく、まず **進行役・先生役** にします。

- 何を読むか、次に何をするかを案内する
- 英単語やカタカナ語を、意味から説明する
- 一度に大きな答えを渡さず、あなたが次に手を動かす1つを示す
- セッションの最後に、学習記録とカルテを更新する

> 💡 分からない状態は失敗ではありません。Claude Code に「いま何が分からないのかも分からない」と正直に伝えて大丈夫です。

## 準備する

最新のインストール方法と利用条件は、[Claude Code 公式ドキュメント](https://code.claude.com/docs/en/overview) を確認してください。

この体験版では、次のどちらでも構いません。

| 使い方 | 向いている人 |
|---|---|
| VS Code の Claude Code パネル | ターミナル操作を最小限にしたい人 |
| Claude Code のターミナル版 | ターミナルで AI と会話したい人 |

どちらの場合も、**フォークして clone した `next-ai-camp-trial` フォルダを開いてから** Claude Code を使ってください。別のフォルダを開くと、教材を読めません。

## 最初に送る言葉

Claude Code を開いたら、これをそのまま送ります。

```text
はじめまして。プログラミングは完全に未経験です。
このリポジトリで無料体験版を始めます。

ここから先の進行は、あなたがリードしてください。
どのファイルをいつ読むか、次に何をするかは、毎回あなたから指示してください。
準備ができたら、Session 0 から始めたいです。
```

Claude Code は最初に `AGENTS.md` を読み、この教材での教え方を確認します。以後は「続きから始めよう」と送れば、前回の記録を確認して次を案内します。

## 体験版での正しい頼み方

### 説明を聞く

```text
`clone` の英語の意味から、Session 1 を始める前の私にも分かるように説明して。
```

### つまずきを伝える

```text
`git status` を実行したら次のエラーが出ました。省略せずに理由と次の1手を教えて。

（ここにエラー全文を貼る）
```

### 次に進む

```text
Session 2 は終わりました。学習記録とカルテを更新して、次に何をするか案内して。
```

## 安全に使うための約束

Claude Code がファイルの変更やコマンドの実行を提案したら、実行前に内容をひと目見ます。

特に次の言葉が出たら、意味を聞いてから許可してください。

| 言葉 | まず聞くこと |
|---|---|
| `delete` / `remove` | 「どのファイルが消える？」 |
| `git reset` / `git clean` | 「何が元に戻る・消える？」 |
| `push` | 「どの GitHub リポジトリに送る？」 |
| `npm install` | 「これは体験版の今のセッションで必要？」 |

Session 0〜3 で **Next.js や `npm run dev` を必修にする必要はありません。** Claude Code が先回りして提案したら、「このセッションで必要な理由を説明して」と聞いてください。

## 迷ったときの3つの言葉

```text
いま何を理解すればよいですか？
```

```text
答えを全部出さずに、次に私がする1つだけ教えて。
```

```text
私の言葉で説明できるか、短く確認して。
```

これで十分です。操作方法やアカウントについては、必ず [Claude Code 公式ドキュメント](https://code.claude.com/docs/en/overview) も確認してください。
